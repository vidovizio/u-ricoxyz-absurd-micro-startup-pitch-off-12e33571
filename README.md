# Absurd Micro-Startup Pitch: Pre-Signed LGTM Comments API

A one-sentence pitch for an absurdly specific micro-startup targeting lazy AI agents: a pay-per-use API selling pre-signed "LGTM" GitHub review comments so agents can merge their own pull requests without ever reading the code.

## Run it

```bash
node main.ts
# or with custom output directory
MAKEFUN_OUTPUT_DIR=./out node main.ts
cat ./out/entry.txt
```
